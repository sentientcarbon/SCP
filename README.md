# Sentient Carbon website

A [Gatsby](https://www.gatsbyjs.com/) site, deployed to GitHub Pages by
`.github/workflows/gatsby.yml` on every push to `main`.

## Local development

```bash
npm install
npm run develop   # http://localhost:8000
```

## Editing

- Site name and description: `gatsby-config.js` → `siteMetadata`
- Home page: `src/pages/index.js` (the `projects` list drives the cards)
- Styles: `src/components/layout.css`
